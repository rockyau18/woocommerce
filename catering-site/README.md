# Lumina Catering HK — HTML Prototype

Premium bilingual (EN/中文) catering website prototype for Hong Kong.

## Preview

Open `index.html` in a browser, or run a local server:

```bash
cd catering-site
python3 -m http.server 8080
```

Then visit: http://localhost:8080

## Pages

- `index.html` — Homepage with all sections
- `services/bar-service.html` — Bar & beverage service page (like 24carrots reference)

## Features

- English default, Traditional Chinese toggle (persists in localStorage)
- Fully responsive (mobile, tablet, desktop)
- Custom AI-generated photography
- WhatsApp integration
- Inquiry form (prototype — no backend)
- Scroll animations & FAQ accordion
